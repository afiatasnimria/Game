Smart Sudoku

Game Rules

  • Fill all empty boxes with numbers from 1 to 9.
  • Each row must contain numbers 1–9 without repeating.
  • Each column must contain numbers 1–9 without repeating.
  • Each 3×3 box must contain numbers 1–9 without repeating.
  • Gray cells are fixed and cannot be changed.
  • Correct inputs turn green.
  • Wrong inputs turn red.
  • Complete the board correctly to win.
