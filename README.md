# 🎮 Mini Games Collection

A collection of fun browser-based mini games built with **HTML, CSS, and JavaScript**.

## 📌 About
This repository contains multiple interactive mini games designed for fun, practice, and improving JavaScript logic-building skills.

All games are lightweight, responsive, and playable directly in the browser.

---

# 🎯 Included Games

## 1. Sliding Puzzle
Arrange the numbered tiles in correct order.

### Features:
- Move counter
- Shuffle system
- Win detection

### Goal:
Arrange numbers from **1 to 8** in sequence.

---

## 2. Whack-a-Mole
Hit the mole before it disappears.

### Features:
- Score tracking
- Timer countdown
- Random mole appearance

### Goal:
Get the highest score within 30 seconds.

---

## 3. Smart Sudoku
Fill the Sudoku board correctly.

### Features:
- Input validation
- Wrong answer highlighting
- Correct answer highlighting
- Win detection

### Goal:
Complete the Sudoku following Sudoku rules.

---

## 4. Easy Space Shooter
Destroy enemy ships and survive.

### Features:
- Auto shooting
- Enemy spawning
- Lives system
- Score system

### Controls:
- Left Arrow / A → Move Left
- Right Arrow / D → Move Right

### Goal:
Survive and destroy enemies.

---

## 5. Pulse (Dodge Rings)
Avoid expanding rings.

### Features:
- Survival score
- Combo bonus
- Wave system
- Collectable orbs

### Controls:
Move mouse to control player.

### Goal:
Survive as long as possible.

---

## 6. Memory Match Game
Find all matching emoji pairs.

### Features:
- Move counter
- Match detection
- Win detection

### Goal:
Match all cards with minimum moves.

---

## 7. Color Reaction Game
Choose the correct color.

### Features:
- Timer
- Score system
- Fast reaction gameplay

### Goal:
Match the displayed text color.

---

## 8. Catch The Box Game
Catch the moving box quickly.

### Features:
- Timer
- Score tracking
- Random movement

### Goal:
Click the box as many times as possible.

---

# 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/your-username/your-repository-name.git
```

2. Open the project folder

```bash
cd your-repository-name
```

3. Open any game file in your browser

Example:

```bash
index.html
```
